## 0. Project Bootstrap

Зафиксировать ТЗ и макеты в первом коммите `master`, опубликовать публичный репозиторий, создать ветку этапа. Добавить инструкции, документы, безопасный шаблон env и минимальные проекты Go/Chi и React/TypeScript/Vite. Закрепить зависимости и подключить базовый CI.

Приёмка включает запуск обоих каркасов, gofmt/vet/tests/build, frontend typecheck/lint/tests/build, PR с зелёными проверками и синхронизацию `master`.

## 1. База данных и API

Подключить PostgreSQL через pgxpool, реализовать валидируемую конфигурацию, lifecycle, liveness `/api/v1/health` и внутренний readiness `/api/v1/ready`. Добавить Goose Up/Down для users, tasks, refresh_tokens и task_history, Compose для БД, миграций и API, а также первые операции OpenAPI.

Приёмка включает Goose Up на пустой PostgreSQL, обратимость миграций на тестовой БД, повторный Up, проверку ограничений, health/readiness при доступной и недоступной БД и соответствующие CI jobs.

## 2. Авторизация и пользователи

Реализовать регистрацию, login, refresh, logout, просмотр профиля, изменение имени и пароля. Выдавать access JWT и защищённую refresh cookie, проверять claims и Origin, ротировать refresh атомарно, ограничивать частоту auth-запросов и отзывать refresh sessions после смены пароля. Синхронизировать OpenAPI.

Приёмка включает ошибки HTTP, уникальность нормализованного email, безопасную верификацию Argon2id, истечение токенов, повторное использование отозванного refresh, logout, смену пароля и защиту чужих данных.

## 3. Задачи и порядок

Реализовать CRUD, валидацию, nullable due date, soft delete, историю статусов и move. Сериализовать task mutations по владельцу и сохранять плотные позиции. Move возвращает каноническую доску. API и примеры отражаются в OpenAPI.

Приёмка включает чтение, создание, изменение и удаление, межколоночные и внутриколоночные moves, пустые списки, конкуренцию и откат транзакций. Проверить недоступность чужих задач для пользователя B по всем операциям.

## 4. API статистики

Считать первое попадание задачи в Done до ограничения периода. Поддержать Days, Weeks, IANA timezone, нулевые интервалы, календарные суммы и изоляцию пользователей. История удалённых и переоткрытых задач сохраняет первое закрытие.

Приёмка включает создание сразу в Done, переход Finish → Done, повторное закрытие, soft delete, переходы календарной недели и месяца, DST и проверку контракта API.

## 5. Основа SPA и экран авторизации

Подключить Tailwind, Inter, Lucide, Router, TanStack Query, React Hook Form и Zod. Заложить общие токены, API client, guard и bootstrap refresh, согласование конкурентных refresh, очистку кеша сессии. Собрать единый `/auth` с двумя панелями на desktop и одной видимой формой на mobile.

Приёмка включает реальные login/register и refresh после reload, отсутствие flash приватного экрана, Back/Forward при синхронизации URL, keyboard focus, reduced motion и доступность формы при клавиатуре. Добавить Playwright smoke в CI вместе с первым сквозным сценарием.

## 6. Доска и формы задач

Собрать Home, шапку и четыре колонки в установленном порядке. Добавить TaskCard и общую форму Add/Edit с валидацией, nullable due date, подтверждениями удаления и закрытия изменённой формы. Хранить данные в API через TanStack Query, показать loading, empty и retry.

Приёмка включает полный CRUD через браузер, корректные цвета и счётчики, сетевые ошибки, фокус модалок, сохранение данных после reload и мобильные формы.

## 7. Перетаскивание

Подключить dnd-kit для смены статуса и сортировки, поддержать overlay, отмену, пустые колонки, touch hold, автопрокрутку и управление клавиатурой. Отправлять move на drop, сериализовать мутации, синхронизировать канонический ответ и откатывать оптимистичное изменение при ошибке.

Приёмка включает перемещение по всем колонкам и внутри списка, сохранение порядка после reload, Escape, drop вне доски, rollback, touch на телефоне и проверку announcements.

## 8. Статистика, профиль и адаптивность

Подключить Recharts к API, переключатель Days/Weeks и сводку недели/месяца. Реализовать редактирование имени, смену пароля, выход и активные счётчики профиля. Довести адаптивность, видимый focus, контраст и клавиатурное управление.

Приёмка включает реальные графики, пустые состояния, обновление после Done, профиль и смену аккаунта. Проверить размеры из §15, включая 320 px, landscape и открытие мобильной клавиатуры.

## 9. Подготовка MVP v1.0.0

Собрать production images и Caddy с SPA fallback и API proxy, проверить запрет доступа к внутренним путям и настройки безопасности. Провести полный архитектурный, функциональный, визуальный и security аудит, прогнать CI, Compose/Caddy и Playwright, проверить backup/restore PostgreSQL. Завершить CI/CD после согласования среды, описать запуск и deployment, подготовить Release Notes.

Приёмка включает все [критерии ТЗ](../SPECIFICATION.md#20-критерии-приёмки), проверенный запуск через Compose/Caddy и стабильный тег `v1.0.0`. Адрес, домен и credentials берутся из выбранного владельцем окружения.

## 10. PWA

Вернуться к PWA и другим дополнениям после принятия MVP. Для каждого согласованного дополнения определить отдельный объём, критерии и ветку.
