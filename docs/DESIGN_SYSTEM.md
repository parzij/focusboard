# Дизайн-система

Стиль GitHub Dark реализован в общих CSS Custom Properties и подключён к Tailwind. Inter Variable поставляется локально через Fontsource с лицензией SIL OFL. Источники требований — [§9–15 ТЗ](../SPECIFICATION.md#9-дизайн-система) и [утверждённые макеты](mockups/).

| Назначение | Цвет |
| --- | --- |
| Фон | `#0D1117` |
| Панель и приподнятая поверхность | `#161B22` и `#1C212B` |
| Нейтральный бордер | `#30363D` |
| Основной и вторичный текст | `#E6EDF3` и `#8B949E` |
| Primary и hover | `#635BFF` и `#5145E0` |
| Ошибка, фокус и график | `#F85149`, `#A5A2FF` и `#8B7DFF` |

| Статус | API | Бордер | Фон колонки |
| --- | --- | --- | --- |
| Not started | `not_started` | `#8B949E` | `#1C212B` |
| In progress | `in_progress` | `#58A6FF` | `#12243D` |
| Finish | `finish` | `#3FB950` | `#102C20` |
| Done | `done` | `#BC8CFF` | `#251B3D` |

Finish означает выполненную работу перед сдачей. Done означает сдачу и окончательное закрытие. Цвет, подпись и иконка используют один статусный config. Для форм и профиля применяются названия из этой таблицы. Данные диаграммы берутся из API.

Inter с локальным WOFF2 и fallback на system-ui. Карточки скругляются на 12 px, панели и модалки на 16 px, auth-контейнер на 20–24 px. Используются Lucide-иконки, видимый focus и touch targets около 44 px.

Пара макетов auth задаёт стиль. В фактической компоновке Sign in начинается слева, приглашение справа. При регистрации панели меняются местами через slide/fade 450–550 ms. На mobile видна одна форма с приглашением под ней. Учитываются фокус, клавиатура и reduced motion.

На широком экране видны четыре колонки. На телефоне доска прокручивается горизонтально вместе с колонками, шапка и график сохраняют ширину экрана. Макет профиля служит ориентиром по поверхностям и компоновке. MVP профиля включает имя, email, инициалы, сводку задач, изменение имени и пароля и выход.

Формы используют видимые labels, Lucide-иконки и поля высотой 48 px. Основная кнопка использует согласованный цвет и белый текст. Для границы интерактивного поля выбран более светлый `--control-border` для различимости на приподнятой поверхности. Контраст границы поля к фону поля составляет 3,10:1. Контраст белого текста к primary составляет 4,70:1, к hover — 6,41:1. Нейтральный бордер `--border` применяется к панелям.

На desktop единая градиентная панель перемещается за 500 мс с `translateX`, формы сменяются через opacity. На mobile формы занимают одну область и сдвигаются горизонтально, приглашение находится ниже. Общая высота рассчитывается по содержимому форм. Неактивная форма получает `inert` и `aria-hidden`. При переключении фокус переходит на заголовок, а в reduced motion переходы отключаются.

Home использует тот же набор поверхностей и токенов. На desktop четыре колонки имеют одинаковую ширину; на mobile горизонтально прокручивается только ряд колонок, каждая колонка сохраняет читаемую ширину. Карточка имеет 1 px бордер цвета статуса, компактную статусную подложку использует только колонка. Формы Add/Edit открываются адаптивным `<dialog>`: центрированная панель на desktop и mobile с вертикальной прокруткой.

Ручка GripVertical занимает 44 × 44 px, иконка 16 px. Перетаскиваемая карточка дублируется в DragOverlay с мягкой тенью, исходная позиция обозначена полупрозрачным контуром. Целевая колонка подсвечивается своим цветом, в списке открывается место под вставку за 180 мс. Reduced motion отключает анимацию вставки и возврата overlay.

Колонки доски имеют постоянный контур 1 px из токена статуса, в том числе в пустом состоянии. При наведении переносимой карточки контур усиливается. Все пустые колонки показывают «No tasks here yet.». В формах задачи Due date отображается как DD/MM/YYYY, календарь и Status используют одинаковый правый отступ для иконок. Закрытие и Cancel выделены приглушённым цветом danger.

У карточки дедлайн отображается как DD MMM (например, 25 Nov). Add task доступна в шапке. Поля общей формы одинаковой ширины, отступы симметричны. Данные дедлайна передаются как YYYY-MM-DD и сохраняются в PostgreSQL DATE. Замена логотипа отложена.

Statistics размещает показатели слева от одного графика на desktop и перемещает их над графиком при узком viewport. График использует существующий токен chart-bar, компактную сетку и таблицу под Chart data для доступа к значениям с клавиатуры. Profile использует ту же шапку и палитру, на mobile секции складываются в одну колонку. Edit profile и Change password переиспользуют центрирование, вертикальную прокрутку и стили действий модалок задач.
