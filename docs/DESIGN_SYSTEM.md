# Дизайн-система

На этапе 0 используется базовая тёмная палитра и системный fallback шрифта. Готовые токены Tailwind, локальный Inter и компоненты вводятся с этапа 5. Источники требований — [§9–15 ТЗ](../SPECIFICATION.md#9-дизайн-система) и [утверждённые макеты](mockups/).

| Назначение | Цвет |
| --- | --- |
| Фон | `#0D1117` |
| Панель и приподнятая поверхность | `#161B22` и `#1C212B` |
| Нейтральный бордер | `#30363D` |
| Основной и вторичный текст | `#E6EDF3` и `#8B949E` |
| Primary и hover | `#635BFF` и `#5145E0` |
| Ошибка, фокус и график | `#F85149`, `#A5A2FF` и `#8B7DFF` |

| Статус | API | Бордер | Фон колонки |
| --- | --- | --- | --- |
| Not started | `not_started` | `#8B949E` | `#1C212B` |
| In progress | `in_progress` | `#58A6FF` | `#12243D` |
| Finish | `finish` | `#3FB950` | `#102C20` |
| Done | `done` | `#BC8CFF` | `#251B3D` |

Finish означает выполненную работу перед сдачей. Done означает сдачу и окончательное закрытие. Цвет, подпись и иконка используют один статусный config. Для форм и профиля применяются названия из этой таблицы. Данные диаграммы берутся из API.

Inter с локальным WOFF2 и fallback на system-ui. Карточки скругляются на 12 px, панели и модалки на 16 px, auth-контейнер на 20–24 px. Используются Lucide-иконки, видимый focus и touch targets около 44 px.

Пара макетов auth задаёт стиль. В фактической компоновке Sign in начинается слева, приглашение справа. При регистрации панели меняются местами через slide/fade 450–550 ms. На mobile видна одна форма с приглашением под ней. Учитываются фокус, клавиатура и reduced motion.

На широком экране видны четыре колонки. На телефоне доска прокручивается горизонтально вместе с колонками, шапка и график сохраняют ширину экрана. Макет профиля служит ориентиром по поверхностям и компоновке. MVP профиля включает имя, email, инициалы, сводку задач, изменение имени и пароля и выход.
