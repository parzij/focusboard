# История изменений

Функциональные этапы 0–8 завершены и слиты в `master`. Следующий этап — [Production Deployment & Release](DEPLOYMENT_PLAN.md). Версия v1.0.0 ещё не выпущена. PWA запланирован после MVP.

## Этап 8. Statistics и Profile ([PR #9](https://github.com/parzij/focusboard/pull/9))

- Периоды Days и Weeks, исторические завершения из API и календарные итоги недели и месяца.
- Защищённый Profile, активные счётчики, обновление имени и смена пароля с повторным входом.
- Адаптивные график, профиль и формы на desktop и mobile.

## Этап 7. Drag & Drop

- Сортировка и перенос задач мышью, с клавиатуры и удержанием на touch.
- Подсветка назначения, предварительная позиция, auto-scroll и обратимый оптимистический перенос.

## Этап 6 — Kanban Board UI

- Добавлен защищённый Home с доской из четырёх фиксированных колонок, серверными задачами, loading/error/empty состояниями и адаптивной горизонтальной прокруткой на телефонах.
- Добавлены карточки с цветом текущего статуса и модалка Add/Edit с проверкой полей, календарной датой, сменой статуса, подтверждением удаления и несохранённых изменений.
- Перетаскивание карточек на этом этапе не реализуется.

## Этап 5 — Frontend & Authentication UI

- Добавлены SPA-маршруты, общие UI-компоненты, локальный Inter и дизайн-токены.
- Реализованы переключение Sign in и Create account, реальная авторизация, восстановление сессии и logout.
- Добавлены координация cookie между вкладками, тесты Vitest и Chromium E2E на PostgreSQL.
- После согласованной правки фирменного знака PR #6 принят и слит в `master`.

## Этап 4 — Statistics API

- Добавлен защищённый отчёт по первому Done с календарными периодами Days и Weeks, сводками недели и месяца и поддержкой IANA timezone.
- PostgreSQL агрегирует историю пользователя в одном снимке. Учитываются закрытия переоткрытых и удалённых задач. Проверены границы дат, DST и существующий частичный индекс Done.
- Расширены OpenAPI, интеграционные проверки и Compose smoke. Описаны локальная интеграция SPA и обязательная ручная приёмка UI с этапа 5.

## Этап 3 — Task Management

- Добавлены шесть защищённых маршрутов задач, частичное редактирование, календарный дедлайн, перемещение и soft delete.
- Мутации сериализуются по владельцу, сохраняют плотные позиции и атомарно записывают историю статусов.
- Добавлены интеграционные сценарии PostgreSQL для конкуренции, изоляции и отката. Compose CI запускает HTTP smoke задач вместе с Authentication.

## Этап 2 — Authentication & Users

- Добавлены регистрация, вход, refresh, выход, чтение и изменение профиля, смена пароля.
- JWT, Argon2id, Origin, refresh cookie, rate limiting и транзакционный отзыв сессий покрыты тестами.
- OpenAPI описывает новые операции. CI запускает интеграционные тесты PostgreSQL и полный HTTP smoke в Compose.

## Этап 1 — База данных и API

- Добавлены валидируемая конфигурация Go, пул pgx, JSON-логи, liveness и внутренний readiness.
- Добавлены четыре SQL-миграции Goose, OpenAPI и Compose с PostgreSQL, задачей миграций и API.
- CI проверяет SQL-ограничения и миграции на реальной PostgreSQL, race detector и запуск Compose.

## Этап 0 — Project Bootstrap

- Добавлены инструкция для Codex, дорожная карта и документация архитектуры, PostgreSQL, API и дизайна.
- Подготовлены минимальные точки входа Go/Chi и React/TypeScript/Vite, шаблон среды и базовый CI с ESLint и Prettier.
- Исходное ТЗ и семь утверждённых макетов зафиксированы отдельно от изменений каркаса.
